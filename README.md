
# NoduleScan AI — Lung Nodule Detection

An AI-powered web application that uses a trained YOLOv8 model to detect and localize potential lung nodules in chest X-ray images.

Upload an image, run the model, view the predicted bounding boxes and confidence scores, and download a summary of the actual inference results.

> **Medical disclaimer:** This application is an AI research and visualization tool. Its predictions may be incorrect and are not a medical diagnosis. It must not be used to make medical decisions or replace evaluation by a qualified healthcare professional.

## Features

- Upload chest X-ray images in PNG, JPG, or JPEG format.
- Preview the selected image before inference.
- Run the existing trained YOLOv8n model.
- View the model's predicted bounding boxes and confidence scores.
- View the original and annotated images.
- Download a results summary where supported.
- Access general lung-health information.
- Use a responsive interface designed for desktop and mobile screens.

The application reports model predictions; it does not confirm or rule out a medical condition.

## Technology Stack

**Frontend:** React, Vite, JavaScript, CSS, and Lucide React.

**Backend:** Python, FastAPI, Uvicorn, and Ultralytics YOLO.

**Image processing:** Pillow, OpenCV, and NumPy.

## Requirements

Install the following software before running the application:

- Windows 10 or Windows 11.
- Python 3.11 recommended.
- Node.js LTS, which includes npm.
- Git, if cloning this repository from GitHub.

Check that Python and Node.js are installed by opening a terminal and running:

```powershell
py -3.11 --version
node --version
npm --version
```

If any command is not recognized, install the corresponding software and reopen your terminal.

## Setup and Run on Windows

Run the backend and frontend in **two separate terminals**.

### 1. Get the project

If you cloned this repository, open a terminal in the project root folder.

Alternatively, download the repository as a ZIP from GitHub and extract it.

The project root is the folder containing `README.md`, `backend`, and `frontend`.

### 2. Set up the backend

Open the first terminal in the project root and run:

```powershell
cd backend
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

The first installation may take some time because the machine-learning dependencies can be large.

Start the backend:

```powershell
python -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

Keep this terminal open while using the application.

If PowerShell blocks virtual-environment activation, run this command in that terminal and try activating again:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

### 3. Set up the frontend

Open a **second terminal** in the project root and run:

```powershell
cd frontend
npm install
npm run dev
```

Keep this terminal open as well.

### 4. Open the application

Open the local frontend address displayed by Vite. By default, it is:

http://localhost:5173

The backend health endpoint is:

http://127.0.0.1:8000/api/health

The FastAPI interactive API documentation is available at:

http://127.0.0.1:8000/docs

### 5. Use the application

1. Open NoduleScan AI in your browser.
2. Choose a chest X-ray image in PNG, JPG, or JPEG format.
3. Review the preview.
4. Click **Detect Nodules** to start inference.
5. Review the returned detections, confidence scores, and annotated image.
6. Download the results if the download option is available.

Results are generated by the backend model. They are not prewritten sample predictions.

## Trained Model

The application is configured to load the existing trained checkpoint from:

```text
backend/models/best.pt
```

The checkpoint should be present in the repository. If it is missing, obtain the original trained checkpoint and place it at the path above.

The backend must not silently substitute a different model or retrain the model.

If the checkpoint cannot be found or loaded, check the backend terminal for the error message.

## Model Evaluation

The following metrics were reported for the model's held-out test set:

| Metric | Result |
|---|---:|
| Precision | 65.11% |
| Recall | 57.98% |
| mAP@50 | 59.82% |
| mAP@50–95 | 27.57% |

These are model evaluation metrics, not clinical performance guarantees. Predictions may be incorrect, and missed detections are possible.

## Troubleshooting

**The backend says the model file is missing**

Confirm that `best.pt` is located at `backend/models/best.pt`.

**Python or a package installation fails**

Check that Python 3.11 is installed and that the backend virtual environment is activated. Read the complete error message in the terminal.

**The frontend cannot connect to the backend**

Confirm that the backend is running on `http://127.0.0.1:8000` and that the frontend is running on the Vite address. Keep both terminals open.

**npm is not recognized**

Install Node.js LTS, then close and reopen the terminal.

**The application returns an inference error**

Check the backend terminal for details. Ensure the checkpoint and required dependencies are installed correctly.
